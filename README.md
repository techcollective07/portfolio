# Bahati Basesela — Portfolio

Personal portfolio of **Bahati Basesela**, built with Next.js, TypeScript and Tailwind CSS.

## Getting started

```bash
bun install
bun run dev
```

Then open http://localhost:3000.

Most of the site content (name, bio, projects, social links) lives in `src/data/index.ts`.
